# Foundation review note

This branch contains the first source-traceable project foundation. It is intentionally not presented as a completed paper inventory.

The repository currently records official archive leads and institutional/third-party discovery leads. Those listings have not yet been fully enumerated against individual original CS PDFs and final answer keys.

Next required work:
1. Visit each official archive and extract its actual file listing.
2. Build a per-year, per-session matrix from the listed files.
3. Download each CS paper and associated official key where terms/access permit.
4. Record file hashes, PDF page counts, cover-page identifiers and question counts.
5. Reconcile archive listings against independent historical indexes.
6. Only then label a paper/session as verified.

Third-party year listings are leads only and must never establish a conducted/not-conducted finding by themselves.
