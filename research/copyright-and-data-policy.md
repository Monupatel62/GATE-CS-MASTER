# Copyright and Repository Data Policy

GATE papers and keys are publicly accessible from official websites, but public access does not automatically grant permission to republish complete question text or original PDF files.

## Public repository rules
- Store official source URLs, paper metadata, hashes, page counts and verification records.
- Do not commit full original question-paper PDFs unless the source's licence or written permission allows redistribution.
- Do not publish a bulk verbatim transcription of copyrighted question text without permission.
- Keep local extraction outputs and downloaded PDFs outside the public Git repository by default.
- Publish original, independently written explanations and derived analytics where lawful.
- Keep short factual answer-key values separate from explanatory prose; preserve official source references.

## Local research workflow
Researchers may download source documents from official portals for their own permitted use, then run the local inspection and extraction tools. Generated local files are ignored by Git by default. Check applicable institutional and legal terms before redistributing any material.

## Provenance
Every local paper file must have a source URL, retrieval date, SHA-256, PDF page count, paper code, year and session/set identity. Never label an uninspected third-party copy as official.
