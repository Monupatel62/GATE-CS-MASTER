# GATE Syllabus History

Syllabus history must be recorded separately for each paper code. Never assume the current syllabus applies to older questions.

For every syllabus version capture:
- Paper code.
- Official syllabus URL and local file hash.
- Effective examination year(s).
- Exact official section and topic wording.
- Added, removed, renamed, merged and split topics.
- Mapping to the canonical taxonomy.
- Confidence and reviewer notes.

The official GATE 2026 site provides separate syllabi for active test papers. The official GATE 2027 site states that syllabi have been revised. This confirms the need for versioning; it does not identify every changed topic.

No complete year-by-year syllabus history is claimed yet. Retrieve official brochures and syllabus PDFs, then compare them line by line.
